# 0003: Visible agent authorship

Date: 2026-09-01
Status: accepted

## Context

Much of this repo is built by directing coding agents. The target roles
are at companies building exactly these tools, and hiding the workflow
would be dishonest and easy to detect.

## Decision

Agent co-author trailers stay in commits, agent-driven sessions are noted
in the log, and the case study discusses the workflow openly. Direction
quality is part of what is being shown.

## Tradeoff accepted

Readers who discount agent-assisted work will discount some commits. The
bet is that the audience worth reaching reads it the other way.
